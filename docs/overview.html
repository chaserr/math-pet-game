项目总览

H5 多学科闯关 + 宠物养成游戏。三大学科（数学 / 语文 / 英语）× 每学科 4 个模块 × 每模块 1000 关。 做题赚积分、爆口粮、养宠物。宠物养成为情感主驱动力，学科练习是温和玩法机制。
名称
数字积木大冒险（Number Block Adventure）
类型
H5 多学科闯关 + 宠物养成
目标用户
全年龄轻松休闲玩家（学龄前 → 成年休闲向，特别适合 6~12 岁儿童）
核心循环
选学科 → 选模块 → 闯关做题 → 赚积分 + 爆口粮 → 养宠物 → 继续挑战更高关卡
关卡总量
3 学科 × 4 模块 × 1000 关 = 12000 关（数学 4 模块全实现；语文/英语各 1 模块 MVP + 3 占位）
关卡锁定
不锁。所有关卡均可随意挑战，已通关的标记 ✅
当前版本
v1.4.0（多学科 + 1000 关 + 数学拆分技巧引导）；文档结构 v1.3.1（多页知识库）

核心特色

  • 🎓 三学科四模块体系：数学（加减乘除）、语文（识字/拼音/组词/成语）、英语（字母/词汇/拼写/句子）
  • 🧠 数学拆分技巧引导：分步骤教孩子凑十法（加）/ 破十法（减），不只是出题
  • 🐱 8 只宠物，4 阶段进化（幼年/成长/强壮/完全体）
  • 🎁 通关爆口粮：按已有宠物随机掉对应口粮
  • 🪙 积分经济：买宠物、买口粮、抽卡萌龙

非目标（首版不做）

  • ❌ 社交 / 排行榜 / PvP
  • ❌ 装扮系统（→ V1.4+）
  • ❌ 关卡锁定 / 强制顺序通关
  • ❌ 实时中途存档（关闭即重启一轮）
  • ❌ 邮箱 / 短信验证
