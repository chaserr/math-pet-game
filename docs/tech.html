层选型说明
前端框架Vue 3 + ViteSFC + Composition API；HMR
状态管理Pinia仅 auth store；其它走组件局部 ref + localStorage
路由vue-router 4history 模式；5 路由（login/home/quiz/shop/pets）；quiz 用 query ?subject&module&stage

后端 / 持久化SupabasePostgreSQL + RLS + Auth

静态资源PNG + SVG放 /public/pets/<species>/{icons,models,...}/

架构演进决策

  • 原计划：Fastify + better-sqlite3，本地单文件部署
  • v1.0 改：→ 纯前端 + Supabase。理由：换设备能玩 / 可分享 / 用现成账号系统 / 部署零成本
  • 取舍：计分、抽卡、掉落等逻辑全部在前端 → 接受作弊风险（休闲单机游戏无对抗压力）
