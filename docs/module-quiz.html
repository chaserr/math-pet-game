四种题目模式

① tile-fill（数字积木拖拽）

  • 用在：数学加减 stage≤50 + 乘除全部
  • 等式 a op b = [slot]*，下方 4 块积木在蓝天草地散布，物理漫游
  • 拖拽 ghost via Teleport to="body"，position:fixed 跟随指针（防 overflow 裁切）
  • 填满自动校验

② multi-step（拆分引导）v1.3 新增

  • 用在：数学加减 stage>50
  • 顶部显示原题 a op b = ? 和提示语
  • 下方步骤列表：所有步骤可见，pending（灰）/ current（金色 pulse）/ done（绿）
  • 底部数字键盘 0-9 + ⌫ + ✓ 确定
  • split 步：填两个空（顺序不敏感）；calc 步：填一个空
  • 单步错 → 扣心 + 清空输入；done 步自动完成
  • 详见 拆分技巧引导

③ choice（四选一）v1.3 新增

  • 用在：语文识字 + 英语字母
  • 大 prompt（emoji 120px / 字母 120px Comic Sans 风字体）
  • 下方 2×2 选项网格，点中后立即揭晓正确/错误
  • 错 → 扣心 + 1.2s 后可重选；对 → 0.6s 后进下一题

④ placeholder（占位）

  • 用在：所有 placeholder=true 的模块
  • 显示 🚧 +「该模块敬请期待」+ 回首页按钮

心 / 计分 / 跳过

  • 每轮 3 颗心，错一题/一步扣 1；心耗尽 → 立即结算
  • 跳过：不扣心 / 不得分 / 连对清零
  • 计分：baseScore(answer) × streakMultiplier(streak) + 满轮 30 bonus

通关推进 + 掉落 api

  • passed = correctCount ≥ 3
  • passed → setClearedStage(subject, module, stage)（自动 max，不回退）
  • 口粮掉落（rollFoodDrops）：correctCount<3 不掉 / =3 掉 1 / =4 掉 2 / perfect 掉 3
  • 掉落 id 池：用户所有 owned pets 的 foodId（无宠物则无掉落）

结算弹层

  • 标题：perfect 🏆 / passed 🎉 / fail 💪
  • 积分 + 答对数 + 满轮 bonus
  • 🎁 掉落区（如有）+ ✨ 进度更新提示（如有）
  • 按钮：回首页 + 下一关（有 next 时）/ 再来一轮
