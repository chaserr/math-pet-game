模块：选关 module v1.4 新增

v1.4 把"数学"模块改造为分类 + 关卡网格。首页点数学模块卡 →「进入选关 →」→ 本页：上方分类 Tab 切换，下方平铺所有关卡按钮，点击直接进入答题。
视图：src/views/StageSelectView.vue 路由：/stages?subject=math&module=add

布局结构

  1. 顶栏：‹ 返回（回首页）+ 模块上下文牌（emoji + 学科 · 模块）+ 积分胶囊
  2. 分类 Tab：横向胶囊式，每项显示分类名 + 已通关 N / 总数 小字。选中态用模块色描边
  3. 进度条：当前分类的进度（颜色 = 模块色）
  4. 关卡网格：grid-template-columns: repeat(auto-fill, minmax(108px, 1fr))，每页 100 关，按需翻页
  5. 分页器：‹ + 数字页码（最多 7 个，居中滚窗）+ ›；超 100 关才出现

关卡按钮（.lv） ui

  • 形状：aspect-ratio: 3 / 1 圆角长方形（border-radius: 18px）
  • 颜色：纯色粉 #F6B8B8，白色粗体文字 + 微阴影；底部一层柔投影；无顶部高光 / 内阴影
  • 标签：
    • 穷举类（10 以内）：显示代表算式 k+? / k×? / ?÷k / ?−k
    • 其它：直接显示关号 1 ~ 500
  • 已通关：背景换为 #dcc7c7 奶粉灰，仍可点击重玩；右上角绿色立体 ✓ 徽章（.lv-check）
  • 交互：hover 上移 2px + brightness 1.05；active 下沉 2px + 阴影塌缩

状态恢复

  • 初次进入：默认选中第一个分类；从答题页返回时按 query.category 自动定位回原分类（QuizView quit 时带上 category）
  • 翻页：本地 page ref，分类切换时归零
  • 已通关读取：isStageCleared(subject, module, category, stage) 实时查询 mpg_progress_v3

跳转

play(stage) → router.push({
  name: 'quiz',
  query: { subject, module, category: currentCat, stage }
})

分类来源

分类定义在 src/lib/mathLevels.js 的 MATH_CATEGORIES。详见 数学关卡分类。

  • 加 / 减 / 乘 / 除 各 5 分类：within10 / within100 / n2 / n3 / n4
  • 数位认知 8 分类：d3 ~ d10（三位数 ~ 十位数）
