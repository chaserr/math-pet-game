模块：首页 / 学科选择 module v1.4 更新

视图：src/views/HomeView.vue 路由：/

布局结构

  1. 顶栏：标题 + 积分胶囊 + 退出
  2. 宠物展示：当前主宠 PetSprite size=140 + 名字/等级
  3. 学科 Tab：3 个胶囊式按钮（数学/语文/英语），选中态用学科色描边 + 浅底
  4. 模块网格：当前学科的模块卡片（math 5 张 / chinese 4 张 / english 4 张），grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))
  5. 次级菜单：🛒 商店 / 🏠 我的宠物

模块卡片（v1.4 分两类）

  • 数学模块卡（含 place）：
    • 进度条：已通关 = Σ 各分类 clearedCount / Σ 各分类 count + 百分比
    • 主按钮：进入选关 → → 跳转 选关页 /stages?subject=math&module=add
    • 不再有跳关弹窗（被关卡网格替代）
  • 语文 / 英语模块卡（保留旧流程）：
    • 进度条：已通关 N / 1000（N = clearedCount(subject, module, 'default')）
    • 按钮 1：继续第 X 关 →（X = nextChallengeStage = max(cleared)+1）
    • 按钮 2：🎯 跳到任意关 → 打开跳关弹窗（数字 1~1000）
  • 占位模块：显示「🚧 敬请期待」，无按钮

启动与加载 v1.4 优化

  • splash 加载占位：App.vue 在 !auth.ready 时显示 🧮 加载页面，避免首屏白屏（main.js 立刻 mount，auth.init() 异步进行）
  • 并行拉取：onMounted 用 Promise.all([auth.refreshProfile(), listMyPets()]) 同时发起，少一次串行往返
  • 路由守卫：await auth.whenReady()，避免 ready 之前误判登录态
