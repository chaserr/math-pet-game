模块：首页 / 学科选择 module v1.3 重构

视图：src/views/HomeView.vue 路由：/

布局结构

  1. 顶栏：标题 + 积分胶囊 + 退出
  2. 宠物展示：当前主宠 PetSprite size=140 + 名字/等级
  3. 学科 Tab（v1.3 新增）：3 个胶囊式按钮（数学/语文/英语），选中态用学科色描边 + 浅底
  4. 模块网格：当前学科的 4 个模块卡片，grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))
  5. 次级菜单：🛒 商店 / 🏠 我的宠物

模块卡片

  • 头部：emoji + 模块名 + 简介
  • 进度条：已通关 N / 1000 + 百分比 + 颜色进度条
  • 按钮 1：继续第 X 关 →（主按钮，背景=模块色）
  • 按钮 2：🎯 跳到任意关 → 打开跳关弹窗
  • 占位模块：显示「🚧 敬请期待」，无按钮

跳关弹窗

  • 输入框：数字 1~1000
  • 快捷按钮：1 / 50 / 100 / 250 / 500 / 750 / 1000
  • 验证后 → router.push({ name:'quiz', query:{ subject, module, stage } })
