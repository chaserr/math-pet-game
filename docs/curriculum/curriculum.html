📖 阅读乐园（Endless Reader 式探索 Hub）v1.11

独立于闯关体系的探索优先入口（路由 /reading，首页英语/语文显示入口卡）。借鉴 Endless Reader 四段式与"无计时·无评分·无失败"铁律，按词驱动一条可插拔阶段管线。

阶段交互组件
✨ 亮相 reveal含义图 + 单元卡飞入，点哪个发哪个音RevealStep.vue
🧩 拼词 spell英语：点字母→发 phoneme→入槽（复用 PhonicsGame）；中文：拼拼音 piece 成字（SyllableSpellStep）。均无失败SpellStep.vue
🔊 读词 say整词放大 + 自动朗读 + 点击复读，音义绑定SayStep.vue
💬 入句 sentence把目标词送回句子（挖空 + 词卡，点错只弹回）SentenceStep.vue

三条扩展接缝（对未来友好，规避"加功能改全项目"）：加词只动 lib/reading/packs.js（英语词包按 phonics tier 自动生成）；加玩法只新增 step 组件并在 ReadingPlayer 注册表登记；换资源只动 lib/reading/resources.js（今日 emoji + Web Speech 兜底，未来换真人录音/插画零改业务）。

真素材注入 seam（v1.12.1，已落地可用）：音频统一收口到 composables/useReadingAudio.js——词数据声明 audio（真人录音 key）则优先 <audio> 播放，文件缺失/加载失败自动回退 TTS；image.kind='asset' 则用原创插画替代 emoji。阶段组件只调 playWord/playUnit/playSentence，对"真音频还是 TTS"无感。素材放 client/public/reading/（约定与示例见该目录 README.md），不放也能玩。v1.12.2：拼词阶段的 PhonicsGame 也经可选 audioAdapter 接入此统一音频（QuizView 计分流不传适配器、保持原 TTS，零影响）。

词包总览（v1.12.3）：英语 = 5 个 phonics tier 包（每包 12 词）+ 手写「农场动物」「做动作」包；中文 = 生活小词 / 认识颜色 / 数一数 / 常见字 / 大自然 共 5 包。新增手写英语包用 mkEn(text,emoji,sentence,units)，音素沿用 phonics-en-bank 口径。

成就徽章（v1.12.3）：词包集齐（已探索数 = 词数）后，词包卡与集字册均显示 🏅；集字册顶部「总成就」横幅显示「已集齐 X / N 个词包」+ 里程碑文案（过半 / 全集齐）。徽章/进度反应统一靠 albumTick，探索后即时刷新。

双模式：探索零压力、进度独立存 mpg_reading_explored_v1（集字册）；每个词包另有"🏆 挑战关"深链到 QuizView（英语→自然拼读 spell，中文→拼音匹配 pinyin），复用计分与口粮经济。中文体验包 zh-life 走完整四段式：拼词阶段用 syllable 变体（SyllableSpellStep，拼拼音 piece 成字、zh-CN 整字读音作锚点，干扰项取自真实声母/韵母库 pinyin-data.js），与英语并列坐实"加阶段=新增组件、不改引擎"。

整包奖励：首次探索完一个词包，发一次温和奖励（金币 + 口粮，数据驱动 pack.reward，缺省兜底）。走 db.grantReward（不写答题历史，与计分 submitRound 分离），只发一次（mpg_reading_rewarded_v1 记账），轻度连到宠物经济而不施压。

Endless Reader 式原创增强（v1.12，借鉴交互、零侵权）：① 宠物陪读——阅读各阶段与庆祝页让 featured 宠物（PetSprite）登场陪伴、随推进做 happy 反应 + 鼓励气泡（ReadingCompanion），把"会说话的小怪兽"替换为我们独有的宠物；② 集字册——顶栏"🗂️ 集字册"浮层，跨词包把已探索词显示为点亮贴纸、未探索为剪影；③ 句子 payoff——SentenceStep 填对后 emoji 弹跳 + 彩纸庆祝；④ 词包扩充——英语每包词量 8→12（库内已有），中文新增「认识颜色」「数一数」主题包。
