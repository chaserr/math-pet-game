教材轴（跟课本学）v1.5 新增

v1.4 的「按能力闯关」轴按 学科 → 模块 → 分类 → 关卡 组织，强调题型与梯度。v1.5 新增 教材轴：按 学科 → 年级 → 上下册 → 单元 → 内容项 组织，强调与小学课本对齐，让家长可以按"今天学的第 X 单元"陪练。 两套轴并存，从首页学科 Tab 下方的「💪 按能力练 / 📚 跟课本学」切换。
设计原则：教材轴是"内容入口"，落地仍复用「按能力练」的题库（练习项通过 ref 指回旧分类）。新增的只有 教学卡（解题技巧）这一种独立形态，其他都是已有题型的重新组织。

教学卡（lesson）—— 三段式

  1. 看演示：固定经典例题（如 10000 - 3847），按"下一步 →"逐步揭示。每步用不同视觉：
    • borrow-out：箭头 10000 ➡️ 9999，右上角积木「1」蹦跳出现
    • column-sub：竖式排版（个十百千对齐 + 减号 + 横线 + 结果）
    • add-back：右上角的「1」蹦回来，文字 6152 + 1 = 6153
    • split / calc / done：复用旧的凑十法/连减法步骤渲染
  2. 自己试：随机生成同类题（genTrickQuiz），数字键盘输入答案，对/错给提示
  3. 完成：返回课本 or「再来一道」

占位策略

每个年级/册/单元/项都可标 placeholder: true。年级网格显示 "有内容"/"整理中" 标签；册内无单元显示 🚧 占位提示；单元 placeholder 则不展开 items。等小学 1–6 年级各册 PDF 到位后再按单元逐个填充。

与「按能力练」的关系

  • 并存：旧的 HomeView 学科 Tab 下方加「💪 按能力练 / 📚 跟课本学」切换，进度互不影响
  • 复用：教材轴的 practice 直接路由到旧 QuizView（带 module + category + stage=1），分数/进度仍按旧分类记录
  • 互补：教材轴回答"今天学什么"，能力轴回答"哪类题练多少"。家长按课本陪练；孩子日常刷题仍用能力轴
