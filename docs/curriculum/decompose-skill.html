拆分技巧引导 v1.3 新增 · v1.6 加法转教学卡

用户的教学目标：不只让孩子背 34-25=9，而是引导他"先减整十，再减个位；个位不够就拆"的思维方式。这是中国小学数学竖式启蒙的核心思路（连减法 / 凑十法）。
当前触发（v1.6）：
  • 加法 within100 一律 tile-fill 拖拽。凑十法不再自动 multi-step，而是作为 教学卡（trickId=make-ten）单独提供，玩家可主动进入学习。
  • 减法 within100 在需要破十时仍走 multi-step 连减法引导（个位不够减就拆）。
  • 其它分类（within10 / n2-n4）一律 tile-fill，不进 multi-step。

算法（src/lib/decompose.js）

减法连减法 decomposeSub(a, b)

  1. 把 b 拆为 整十 bTens + 个位 bOnes
  2. 先 a - bTens
  3. 再 cur - bOnes：
    • 若 cur 的个位 ≥ bOnes：直接减
    • 否则把 bOnes 拆为 cur%10 + 剩余，先减到整十，再减剩余

示例 1：34 - 25（用户给的例子）

125 = 20 + 5
先把 25 拆成 20 + 5（用户填两个空）
234 - 20 = 14
先减整十
35 = 4 + 1
14 的个位 4 < 5，把 5 拆成 4 + 1
414 - 4 = 10
先减到整十
510 - 1 = 9
再减剩下的
✓✨ 34 - 25 = 9

加法凑十法 decomposeAdd(a, b)

  1. 把 b 拆为整十 + 个位
  2. 先 a + bTens
  3. 再 cur + bOnes：
    • 若 cur%10 + bOnes ≤ 10：直接加
    • 否则把 bOnes 拆为 (10 - cur%10) + 剩余，先凑到整十，再加剩余

示例 2：28 + 35

135 = 30 + 5
先把 35 拆成 30 + 5
228 + 30 = 58
先加整十
35 = 2 + 3
58 的个位 8 + 5 > 10，凑十：拆 5 = 2 + 3
458 + 2 = 60
先凑到整十
560 + 3 = 63
再加剩下的
✓✨ 28 + 35 = 63

UI 实现（QuizView multi-step 模式）

  • 步骤列表：所有步骤渲染为竖向卡片，pending（灰）/ current（金色 pulse 高亮）/ done（绿）
  • 数字键盘：底部 0-9 + ⌫ + ✓ 确定（无需拖拽，单步输入）
  • 输入校验：split 步必须填 2 个数（顺序不敏感）；calc 步填 1 个数
  • 错误处理：单步错 = 扣 1 颗心 + 清空输入重试；心耗尽提前结算
  • 跳过 done 步：最后一步 { kind: 'done' } 自动完成，触发 onCorrect

整万数减法 · 减1法 v1.5 新增 · trickId=borrow-trick

触发：教学卡专用（教材轴 · 四上 第1单元 / 任何路径手动指向 /lesson?trick=borrow-trick），不进入随机闯关。 isBorrowTrickApplicable(a, b)：被减数形如 10…0（1 后跟若干 0）且 0 < b < a。

思路：先借走 1，竖式秒算，再加回来

  1. 借出 1：10000 → 9999（积木「1」蹦到旁边等着）
  2. 竖式：9999 − 3847 = 6152（各位都是 9，不退位）
  3. 加回 1：6152 + 1 = 6153（旁边的「1」蹦回来）

示例 3：10000 − 3847（用户给的例子）

110000 ➡️ 9999
先借走 1（积木「1」蹦到旁边）
29999 − 3847 = 6152
每位都是 9，不退位，竖式秒算
36152 + 1 = 6153
别忘了把借走的 1 加回来！（积木「1」蹦回来）
✓✨ 10000 − 3847 = 6153

新增的步骤 kind

kind字段渲染
borrow-out{ from, to, borrow, hint }箭头 from ➡️ to + 蹦跳「1」入场
column-sub{ a, b, answer, digits, hint }竖式（个十百千… 对齐 + 减号 + 横线 + 结果）
add-back{ a, b, answer, hint }文字 a + b = answer + 蹦跳「1」归位动画
