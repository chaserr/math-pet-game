关卡进度（localStorage v2）shared

文件：src/lib/progress.js
存储键
mpg_progress_v2（JSON 对象）
数据格式
{"math.add": 42, "math.sub": 10, "chinese.recognize": 3}（按 subject.module → cleared stage 数字）
API
getClearedStage(s, m) 已通关最高（0=尚未）
setClearedStage(s, m, n) 仅当 n > 当前才写入（防回退）
nextChallengeStage(s, m) = cleared+1，封顶 1000
isStageCleared(s, m, id) id ≤ cleared
progressSummary() 全部进度的扁平数组
设计取舍
不上 Supabase：12000 关进度小型 JSON 即可；想跨设备同步时再升级

拆分算法 api v1.3 新增

文件：src/lib/decompose.js

导出 decomposeAdd(a, b) / decomposeSub(a, b) / decompose(a, b, op)。返回步骤数组（详见 拆分技巧引导）。
