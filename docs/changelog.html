回合 #92026-05-22 v1.5.0 · 教材轴 + 教学卡（减1法 / 凑十法） majorfeat

用户原话

"接下来我需要增加需求：我现在已经有小学1到6年级的所有教材pdf，我想根据这些pdf设计一些好玩的课本教学内容以及拓展内容还有比如一年级有上下册，每册有对应的第一章第二章等，根据这些来设计。另外还有一些专项练习，比如语文的拼音，数学的九九乘法表等。还有一些解题技巧：比如大数减去小数 10000-3847 = 从10000减去1，就是和被减数时同样的，然后列竖式就很好计算了，最后要提醒别忘记加上1，这个1可以是数字积木里的1，在旁边蹦蹦跳跳（当做出从10000里减去1之后这个就会出现）。另外还有那种凑十法也属于解题技巧。而语文有相对应的必背诗词，必学汉字，给汉字注音，根据拼音学汉字（每个年级一个）。先说这么多需求，你可以进行头脑风暴看看在现有的基础上如何设计上述功能。注意要先设计再实现，实现后需要同步到文档。"

决策（设计后实施）

  • 新增「教材轴」与「按能力练」并存，首页学科 Tab 下方加切换按钮。教材轴只是"内容入口"，练习落地仍复用旧题库（ref 指回旧 module+category）。
  • 本轮搭完整框架 + 占位：6 年级 × 上下册全部建好节点；先实现 3 个有用样板（一上数学/二上数学/四上数学）+ 一上语文占位拼音 + 复用看图识字。其余等用户逐 PDF 提供内容时再填。
  • 解题技巧抽出为教学卡（lesson）独立形态：三段式（看演示 → 自己试 → 完成），与随机闯关分开。首发两张：borrow-trick（10000 系减法减1法，含积木「1」蹦跳/归位动画）+ make-ten（凑十法，复用 decomposeAdd）。
  • 语文「必背诗词 / 必学汉字 / 注音 / 拼音学字」每年级一个，本轮均按占位骨架接入，等用户提供 PDF 后再填。

实现

  • 数据层：新建 lib/textbook.js（GRADES / VOLUMES / TEXTBOOK / ITEM_TYPES + 一组查询助手 textbookHasSubject / getUnits / gradeHasContent）
  • 视图：新建 views/TextbookView.vue（年级网格 → 册 Tab → 单元卡 → 内容项，URL query 同步浏览状态）+ views/LessonView.vue（演示步骤逐步揭示 + 数字键盘自测 + 蹦跳的「1」动画 keyframes hop / hop-back）
  • 出题器：useQuizGen.js 新增 LESSON_META / buildBorrowTrick / buildMakeTen / lessonInfo(trickId) / genTrickQuiz(trickId)
  • 拆分库：lib/decompose.js 新增 isBorrowTrickApplicable / decomposeBorrowTrick + 三种新 kind：borrow-out / column-sub / add-back
  • 路由 / 首页：router/index.js 加 /textbook + /lesson；HomeView.vue 加「💪 按能力练 / 📚 跟课本学」切换

影响文件

新（代码）：client/src/lib/textbook.js · client/src/views/TextbookView.vue · client/src/views/LessonView.vue
改（代码）：client/src/lib/decompose.js（+减1法）· client/src/composables/useQuizGen.js（+教学卡）· client/src/router/index.js（+2 路由）· client/src/views/HomeView.vue（+模式切换）
新（文档）：docs/textbook.html
改（文档）：docs/index.html（卡片 + 最新变更面板 + 版本号 v1.5.0）· docs/decompose-skill.html（+减1法章节）· docs/shared.js（PAGES + 教材轴）· 其余 18 个 html 文件的 aside.sidebar（+教材轴链接）· docs/changelog.html（本条）

回合 #82026-05-22 v1.4.0 · 分类层 + 数位认知 + 选关网格 majorfeatrefactorui

用户原话（多轮整合）

"数学的加法里面不要有太多 10 以内的算法，或者关卡注明：10 以内的算法，100 以内的算法，2 个数相加，3 个相加，4 个数相加等这样的分类，每个分类下面 500 关… 关卡通过那么按钮就变成灰色但是还可以继续点击玩。加减乘除都一样，其中 10 以内的算法只需要穷举列出来比如 1+1，1+2，1+3，一直到 9+9 这么多即可。另外还要增加个十百千位，比如列出 1000，让用户拖拽，在空格处标记个十百千…这个可以单独作为一个分类和加减乘除并列。"

"把 10 以内的也分为 9 个关卡吧，每个关卡 9 道题。"

"从算法页面点击左上角返回直接返回到了首页，应该是返回到关卡页面。"

"程序首页无法加载比较慢。"

"关卡背景色修改为蓝色然后饱满一点不要正正方方的 →（最终用 #F6B8B8 不要高光）"

实现

  • 数学三层结构：Subject → Module → Category → Stage。加减乘除各新增 5 分类（within10 / within100 / n2 / n3 / n4）；新模块 place（数位认知）8 分类（d3~d10）。详见 数学关卡分类。
  • 10 以内固定 9 关 × 9 题：按"被固定的那个操作数"分关，按钮显示代表标签（如 1+? / ?÷5）
  • 数位认知：tile-fill 新增 layout: 'place' 布局，大数字 + 个/十/百/千… 标签格子，复用积木拖拽
  • 新页 选关：分类 Tab + 关卡网格（粉色 #F6B8B8 长方形 + 已通关灰显仍可点）+ 分页（每页 100 关）
  • 进度结构换代：mpg_progress_v2（max stage）→ mpg_progress_v3（按分类记录已通关关号集合，支持单关灰显与重玩）
  • 计分按轮次大小：scoreRound 新增 count / passed；passed = correctCount ≥ ⌈count×0.6⌉；perfect = 全对；rollFoodDrops 按比例派发，使单题关也能掉口粮
  • 首屏 splash：main.js 不再被 auth.init 阻塞 mount；App.vue !auth.ready 时显示加载占位；路由守卫 await auth.whenReady()；HomeView refreshProfile + listMyPets 并行
  • 返回按钮：QuizView 顶栏返回，math 学科回 /stages?subject&module&category（自动定位回原分类 Tab），其它学科回首页

影响文件

新：views/StageSelectView.vue（选关页）
改：catalog.js（math 加 place 模块） · useQuizGen.js（按分类出题 + 多操作数 tile-fill + place 布局） · lib/progress.js（v3 集合） · lib/gameLogic.js（passed/count） · db.js（rollFoodDrops 按比例 + ctx 带 category） · stores/auth.js（_readyPromise/whenReady） · main.js · App.vue · router/index.js（新 stages 路由 + 守卫 await） · views/HomeView.vue（math 卡进入选关，并行加载） · views/QuizView.vue（category + roundSize + place 布局 + 返回到选关）

回合 #62026-05-21 v1.4.0 · 三学科 + 1000 关 + 拆分引导 majorfeatrefactor

"关卡不再锁住，分为语文数学英语三大类，每个类别下面有相对于的模块，比如数学下面有加减乘除小类，每小类下面有1000关，每关5道题。语文和英语暂时没想好怎么做或者你可以自己思考或者借鉴网络上类似的游戏去实现。另外关于这个加减法，我还想引导小朋友运用技巧做题，比如34-25，引导用户拆分为30+4，25拆违20+5，所以34-25=34-20=14-5=14-4-1=9这样的一个思路去解决问题，加法类似"

  • 拆分技巧：新建 decompose.js（连减法 + 凑十法，详见 拆分技巧引导）
