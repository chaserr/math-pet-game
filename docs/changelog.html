回合 #72026-05-22 v1.3.1 · 知识库多页化 refactorspec

用户原话

"也不仅仅是一个 index.html 里面装了所有东西，可以不同模块都有自己的 html，然后 index.html 相当于知识库的主页，由主页可以跳转到各个模块这样的。另外这种布局方式可以作为后续任何项目的一个总纲"

决策

  • 单文件 index.html（64KB 全装）→ 拆为多页本地网站
  • index.html 改为知识库主页：Hero + 卡片网格导航（5 分组）+ 最新变更/待处理面板
  • 18 个模块/章节各自独立 HTML（overview/quick-start/tech/curriculum/difficulty/decompose-skill/module-*×5/data-model/shared-systems/assets/files/change-protocol/changelog/known-issues）
  • 抽公共：shared.css（顶栏/侧栏/卡片/表格/tag/页脚）+ shared.js（侧栏当前页高亮 + 跨页 fetch 搜索 + "/"聚焦）
  • 每页统一骨架：顶栏（品牌+面包屑+搜索）+ 左侧栏（同级导航高亮）+ 主内容 + 页脚（上一页/主页/下一页）
  • 定为通用准则：此多页结构作为后续任何项目的文档总纲，已写入 memory feedback_multi_page_knowledge_base

影响文件

新：docs/shared.css · docs/shared.js · 18 个模块 HTML
改：docs/index.html（单文件 → 主页导航）
memory：新增 feedback_multi_page_knowledge_base.md（通用），更新 feedback_html_docs.md（项目特化）+ MEMORY.md

回合 #62026-05-21 v1.3.0 · 三学科 + 1000 关 + 拆分引导 majorfeatrefactor

用户原话

"关卡不再锁住，分为语文数学英语三大类，每个类别下面有相对于的模块，比如数学下面有加减乘除小类，每小类下面有1000关，每关5道题。语文和英语暂时没想好怎么做或者你可以自己思考或者借鉴网络上类似的游戏去实现。另外关于这个加减法，我还想引导小朋友运用技巧做题，比如34-25，引导用户拆分为30+4，25拆违20+5，所以34-25=34-20=14-5=14-4-1=9这样的一个思路去解决问题，加法类似"

实现

  • 关卡不锁：删除 5 关线性解锁，所有关卡可挑战
  • 三学科四模块：SUBJECTS(3) × MODULES(4 each) × STAGES_PER_MODULE=1000
  • 难度梯度：每模块 params(stage) 函数算法生成（详见 数学难度梯度）
  • 语文 MVP：看图识字（emoji↔汉字 4 选 1）；英语 MVP：字母大小写匹配；其余 6 模块占位
  • 拆分技巧：新建 decompose.js（连减法 + 凑十法，详见 拆分技巧引导）
  • 题目四模式：tile-fill / multi-step / choice / placeholder
  • 进度持久化：localStorage mpg_progress_v2

影响文件

改：catalog.js · useQuizGen.js · progress.js · db.js · HomeView.vue · QuizView.vue
新：lib/decompose.js
构建：通过（QuizView 22.9KB / HomeView 4.6KB / 总 333KB gz 102KB）
