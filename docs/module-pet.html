喂食 / 升级 / 进化 api

// db.js#feed(petId)
食物 exp 计入 user_pets.exp
while level < MAX_LEVEL && exp ≥ expForLevel(level):
   exp -= expForLevel(level); level += 1; leveledUp = true
亲密度 += food.intimacy（封顶 100）
user_foods.quantity -= 1
返回 { leveledUp, newlyUnlocked, pet }

expForLevel(level) = 50 × level    // MAX_LEVEL = 10

进化特效（playEvolve）

当 afterStage > beforeStage，触发 2.2s 全屏特效：

  • .evo-overlay 暗紫径向罩
  • .evo-rings 三层 ring 扩散动画（delay 0/0.4/0.8s）
  • .evo-pet 主立绘 evopop 缩放 + 阶段色光晕 drop-shadow(0 0 24px var(--evo))
  • 文字「✨ 进化！{stageName}」+ 2.2s 后 toast「✨ 进化成「xxx」啦！」
