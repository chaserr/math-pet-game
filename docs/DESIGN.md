# 数字积木大冒险 — 设计文档（PRD v1.0）

> 一个 H5 数学闯关 + 宠物养成游戏。0-100 加减法做题赚积分，积分购买与喂养宠物。
> 文档状态：**Understanding Lock 已确认**，可进入实现阶段。
> 最后更新：2026-05-21

---

## 1. 项目总览

| 项 | 内容 |
|---|---|
| 名称（暂定） | 数字积木大冒险 |
| 类型 | H5 数学闯关 + 宠物养成 |
| 目标用户 | 全年龄轻松休闲玩家 |
| 核心循环 | 做题 → 赚积分 → 买/养宠物 → 解锁更多内容 → 继续做题 |
| 定位 | 宠物养成为主驱动，数学为温和玩法机制（非教育严肃向） |

### 1.1 为什么做

用"养宠物"的情感驱动力，把略枯燥的数学练习包装成可持续游玩的休闲养成体验。

### 1.2 目标平台

- **首版**：H5（Web），平板 + 桌面优先（触控 + 鼠标双支持）
- 手机能跑但不做专门优化
- 本地部署，单机运行

## 3. 核心玩法

### 3.1 题目生成

- 范围：**0-100 加减法**，运算双方与结果均在 0-100（不出负数、不超 100）
- 含一位数与两位数混合
- 加法：`a + b = ?`，约束 `a+b ≤ 100`
- 减法：`a - b = ?`，约束 `a ≥ b`（结果 ≥ 0）

### 3.2 答题机制（数字积木拖拽）

1. 题目展示，等号后有 N 个**空槽**，N = 正确答案的位数
   - 答案 `7` → 1 个空槽
   - 答案 `15` → 2 个空槽
   - 答案 `100` → 3 个空槽
2. 屏幕下方有**固定 4 块数字积木**（0-9 的拟人角色）：
   - 包含正确答案所需的每一位数字
   - 其余用干扰项补足到 4 块
   - 例：答案 15 → 候选含 `1` `5` + 2 个干扰；答案 100 → 含 `1` `0` `0`(两个0) + 1 个干扰
3. 玩家**拖拽**积木填入空槽（顺序敏感：1 在前 5 在后 = 15）
4. **所有空槽填满后自动检查**

### 3.3 对错反馈

- ✅ **答对**：积木落位动画 + "+N 分"飘字 + 宠物开心，延迟 ~1.5 秒自动进下一题
- ❌ **答错**：
  - 扣 1 颗心
  - 填入的积木**跳回积木池**（GSAP 弹跳动画）
  - 显示鼓励文案（"再试一次！" / "差一点点～"）
  - 玩家可**重试**或点击**跳过**

### 3.4 回合与生命值

- **一轮 = 5 题**
- 一轮共 **3 颗心**
- 答错 1 次扣 1 颗心
- **心耗尽 → 本轮提前结束，结算已获得的积分**
- 跳过：不扣心、不得分
- 下一轮重置 3 颗心

### 3.5 计分规则

| 项 | 值 |
|---|---|
| 基础分（按答案位数） | 1 位 +5 / 2 位 +10 / 3 位 +15 |
| 连对加成 | 第 1 题 ×1.0、连对 2 题 ×1.2、连对 ≥3 题 ×1.5 |
| 满轮奖励 | 一轮 5 题全对额外 +30 |

> 答错或跳过会重置连对计数。

## 4. 美术风格

- **风格**：Numberblocks 拟人 Q 版（堆叠方块 + 圆眼睛 + 表情 + 腮红）
- **载体**：手写 SVG 矢量图（高清、轻量、可改色、易动画）
- **原创性**：自绘纹理与配色，避免 IP 侵权（保留"N 个方块堆叠 + 拟人"的设计语言，不照搬官方角色）
- **可替换架构**：资源放 `/client/src/assets/svg/{blocks,pets,foods,ui}/`，命名 `<category>_<id>_<state>.svg`，后期可由插画师/AI 出图替换，无需改代码

### 4.1 数字积木配色（0-9）

| 数字 | 颜色 | 方块数 |
|---|---|---|
| 0 | 灰白（幽灵描边块） | 特殊 |
| 1 | 红 | 1 |
| 2 | 橙 | 2 |
| 3 | 黄 | 3 |
| 4 | 绿 | 4 |
| 5 | 蓝 | 5 |
| 6 | 靛 | 6 |
| 7 | 紫 | 7 |
| 8 | 粉 | 8 |

> 多位数答案（如 15）由 `1` 和 `5` 两个独立角色并排展示，不为每个 10-100 的数字单独建模。

| 8 | 🐉 萌龙 Long | 抽卡限定 | 50 积分/抽 | 火龙果 |

### 5.2 三种获取方式

1. **明码标价商店**：1-4 号宠物随时可买
2. **解锁商店**：5-7 号宠物达成条件后出现在商店，可用积分购买
3. **抽卡蛋**：50 积分/抽，随机出宠物（含 8 号萌龙限定）；**抽到重复宠物 → 自动转化为 3 包该宠物专属口粮**

### 5.3 宠物成长（V1：等级 + 亲密度）

- **等级**：1-10 级。喂口粮获得 EXP，满 EXP 自动升级，每级所需 EXP 递增
- **亲密度**：0-100。喂食/互动增加，独立于等级
- **装扮**：→ V1.1（数据库预留表结构）
- **成长阶段**：4 阶，当前按等级映射：Lv.1 幼年 / Lv.3 成长 / Lv.6 强壮 / Lv.9 完全体

### 5.4 口粮系统

- **每只宠物专属口粮，不可互用**（小猫只吃小鱼干，小狗只吃肉骨头……）
- 口粮在商店用积分购买
- 喂食增加对应宠物的 EXP 与亲密度

### 5.5 饥饿机制

- 宠物会"饿"：长期不喂 → 首页表情变难过 / 呜咽动画
- 喂食后恢复开心
- **不扣属性、不掉级、不死亡**（全年龄友好，无心理压力）

## 7. 技术架构

### 7.1 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | Vue 3 + Vite | SFC 直观、生态成熟、迭代快 |
| 状态管理 | Pinia | 轻量、类型友好 |
| 动画 | GSAP | 积木跳回/落位等流畅动画 |
| 拖拽 | 原生 Pointer Events（统一鼠标+触控） | 平板桌面双支持 |
| 后端 | Node.js + Fastify | 轻量高性能 |
| 数据库 | better-sqlite3（SQLite 单文件） | 本地部署、零配置 |
| 鉴权 | JWT（本地存储 token） | 无状态、简单 |

### 7.2 目录结构

```
math-pet-game/
├── client/                       # Vue 3 + Vite 前端
│   ├── src/
│   │   ├── components/           # NumberBlock / Pet / HeartBar / ShopCard ...
│   │   ├── views/                # Login / Home / Quiz / Shop / PetHouse
│   │   ├── stores/               # auth / game / pets / inventory (Pinia)
│   │   ├── composables/          # useDrag / useQuizGen / useScore
│   │   └── assets/svg/           # blocks/ pets/ foods/ ui/ （手写 SVG）
│   └── vite.config.js
├── server/                       # Node.js + Fastify 后端
│   ├── src/
│   │   ├── routes/               # auth / game / shop / pets
│   │   ├── db/                   # schema.sql / migrations / connection
│   │   └── services/             # scoring / gacha / breeding
│   └── data/game.db              # SQLite（运行时生成）
└── docs/DESIGN.md
```

### 7.3 数据库表（初版）

```
users          (id, email, password_hash, points, main_level, created_at)
pets_catalog   (id, name, species, acquire_type, price, unlock_cond, food_id)   -- 静态配置
user_pets      (id, user_id, pet_id, level, exp, intimacy, last_fed_at)
foods_catalog  (id, name, pet_id, price)                                        -- 静态配置
user_foods     (id, user_id, food_id, quantity)
answer_history (id, user_id, question, user_answer, time_ms, error_count, created_at)
```

## 10. 实现里程碑（建议分阶段）

- **M0 脚手架**：前后端工程初始化、SQLite 连接、可跑通 hello world
- **M1 美术资源**：0-9 数字积木 SVG + 8 宠物（3 状态）+ 8 口粮 + UI 图标

- **M4 养成**：商店（明购/解锁/抽卡）+ 宠物屋 + 喂食 + 升级 + 亲密度
- **M5 答题历史 + 收尾**：历史记录写入、整体联调、平板/桌面适配测试
