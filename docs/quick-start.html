快速开始

环境

  • Node.js ≥ 18
  • Supabase 项目已就绪，前端 .env 注入 VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY
  • 开发期需在 Supabase 后台关闭 Confirm email

常用命令

cd client
npm install
npm run dev               # http://localhost:5173
npm run build             # → dist/

# 已知问题：构建报 @rollup/rollup-darwin-* MODULE_NOT_FOUND
rm -rf node_modules package-lock.json && npm install
